SANTHIYA S. — AI/ML ENGINEER PORTFOLIO

============================================================
Overview
============================================================
A modern, responsive, elegant portfolio website for Santhiya S., Aspiring AI/ML Engineer.
Built with clean semantic HTML5, modern responsive CSS (White & Soft Lavender Theme with Purple Accents), and vanilla JavaScript.

============================================================
How to View
============================================================
1. Open this folder in your browser or double-click index.html.
2. In VS Code, you can also use the Live Server extension (Right-click index.html -> "Open with Live Server").

============================================================
Files in this Project
============================================================
- index.html            : Upgraded semantic portfolio structure with all 8 core sections.
- style.css             : White & Soft Lavender design system, soft shadows, responsive breakpoints.
- script.js             : Mobile nav toggle, scroll spy active link highlighting, dynamic year, resume check & modal, and contact form validation.
- portfolio_profile.jpg : Genuine profile portrait in the root directory.
- Santhiya_Resume.pdf   : Place your PDF resume here to enable direct one-click downloading.
